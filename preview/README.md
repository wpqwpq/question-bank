# 切割预览

只读地看 `data/` 里切好的题图。选范围 → 选卷 → 看图。

## 启动

双击 `start.cmd`，浏览器会自动打开 `http://127.0.0.1:8645`。
也可以直接 `python preview/server.py`。

- 纯标准库，不需要装任何东西（Python 3.8+）
- 端口 8645 起，被占用自动往后找
- `PREVIEW_NO_OPEN=1` 启动则不自动开浏览器

## 怎么用

1. **选范围**：考试局 → 资格考试 → 学科，点「进入」
2. **选卷**：左栏按年份倒序列出该学科所有卷，点一卷
3. **看图**：右栏按题号顺序显示 `assets/qNN.webp`

### 图上有什么

- **选项热区**（绿色实线框 + 左侧字母标签）：选择题每个 A–D 选项一整块，坐标来自 `layout.json` 的 `options`
  - 只有**切出了热区**的选择题才有（`question_type=mcq` 且 `cut.json` 里有 `option_hotzones`）；其它题不画
  - 一题多套 A–D（化学 Section A 的 `(a)(b)` 各一套）按套别换色：套 a 绿、套 b 紫、套 c 青
  - 题卡头部会显示「热区 4 / 热区 8」这样的个数
  - 老卷没有 `layout.options` 就不显示，不会报错
- **小问切割线**（橙色虚线，右侧标签）：位置来自 `assets/qNN.layout.json` 的 `subquestions.box.y`，画的是**题卷侧**的小问标签行
- **作答区切割线**（蓝色虚线，左侧标签）：画的是 `render_subsplit` **真实的切片起点**，不是 `areas` 的起点
  - 首组：`answer_block` 顶（册内题号行，含 `(a)(i)` 与右对齐分值行）
  - 其余组：上一组作答区底部向上扩 2px（间隙里的 `(b)`/`(i)` 标签行随之保留）
  - `areas`（作答内容起点）在这条线**下方** 22–280pt（中位 36–60pt），直接画它跟切出来的子图对不上（2026-10-19 踩过）
- **小问个数**：题卡头部显示，例如 `3 个小问`；有答题册的卷多一个 `作答区 4 段`
- **跨页标记**：`cut.json` 里 `regions` 多于一段时显示 `跨 2 段（P5,6）`

顶栏「热区」「小问线」「作答区线」三个按钮可以分别关掉。

### 键盘

| 键 | 作用 |
|---|---|
| `j` / `k` | 下一题 / 上一题 |
| `[` / `]` | 上一卷 / 下一卷 |
| `Esc` | 关掉放大图 |

点图片可以放大看原尺寸。

## URL 直达

带 hash 可以直接进某一卷，存书签很方便：

```
http://127.0.0.1:8645/#edexcel/a-level/physics/2020-jan-wph11
```

## 边界

- **全程只读**：`data/` 下每个文件都是 `open(..., 'rb')`，一个字节都不写
- 卷列表的题数是从 `assets/` 文件名数出来的，不读 `cut.json`
- 没有 `cut.json` 的卷也能看，只是没有分值/题型/小问信息
- 没有 `assets/` 的卷点进去显示「还没切」
- 不建索引、不生成缩略图 —— 一次性只渲染一卷，浏览器自己懒加载
