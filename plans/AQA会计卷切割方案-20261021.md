# OxfordAQA 9615 会计卷切割方案

> 2026-10-21 · 对 `downloadPapers/_new/AQA_9615_Accounting` 全部 16 份 QP 逐页实测后的方案。
> 用户要求：**不保留答题区，小问直接拼接**。方案未落任何切割产物。

---

## 0 结论先行

| 项 | 实测结果 |
|---|---|
| 源内卷数 | 16 份 QP，但**只有 6 份是 9615 国际卷**，另外 10 份是英国本土 AQA **7127** 卷（见 §1） |
| 可切题数 | 6 卷 × 16 题 = **96 题**；若连 7127 一起切，10 卷 × 17 题 = 170 题，合计 **266 题** |
| 卷面满分 | 9615：U1/U2 = 80，U3/U4 = 90；7127：120 |
| 结构 | Section A（MCQ，涂卡）+ Section B + Section C（长答），**全卷连续题号 1–16/17** |
| 答题册 | **没有**。题面与作答区同页（Answer Book 式），所以不产 `answer_block` / `answer_regions` |
| 答题区形态 | 实线横排 + 空表格行 + 大片空白，**不是 Edexcel 那种点线** |
| 压缩实测 | 整卷 16 757pt → **7 614pt（45%）**；最大单题 1 161pt（≈3 225px @200dpi），离 WebP 16 383px 上限很远 |
| 新增能力 | 「删无文字行带」——同页拆多段 region，渲染层已原生支持，**不用改渲染代码** |

**一句话**：这科能切，而且压得比预期狠；真正的风险不在切，在**源混了 10 卷英国本土 7127**。

## 1 必须先说清的事：16 卷里有 10 卷不是 9615

按封面 + 页脚实测：

| 文件 | 封面 | 页脚 | 卷面分 | 题数 | 身份 |
|---|---|---|---|---|---|
| 2025-june u1/u2 | `INTERNATIONAL AS` | `IB/M/Jun25/G4001/V7` | 80 | 16 | ✅ 9615 |
| 2026-jan u1/u2 | `INTERNATIONAL AS` | `IB/M/Jan26/G4002/V4` | 80 | 16 | ✅ 9615 |
| 2026-june u3/u4 | `INTERNATIONAL A-LEVEL` | `IB/M/Jun26/G4003/V5` | 90 | 16 | ✅ 9615（A2） |
| 2020-oct ~ 2024-june（10 卷） | `A-level` | `IB/G/Jun20/7127/1` | **120** | **17** | ❌ 英国本土 7127 |

版式也跟着变：7127 用 `AQAChevinPro` 字体、题面套一个方框、Section A 有 11 题；9615 用 Arial、题面无框、Section A 有 8 题。

> 这不是「同一资格的不同年份」，是**两套大纲**（7127 UK A-level vs 9615 International A-level）。混进同一个 `data/aqa/a-level/accounting/` 会把两组考点、两种分值结构、两种题量揉在一起。

## 2 实测版式

### 2.1 9615（6 卷，28–32 页）

```
p1        封面（For Examiner's Use 阅卷表）
p2–p9     Section A   MCQ 1–8，每题 1 分，A–D 四选项 + 涂圈
p10–p21   Section B   9–15，结构化；每小问 = 题面 + 作答区（横线 / 空表格）
p22–p25   Section C   16，情景材料（方框）+ 长答（12 分，21 条横线）
p26       DO NOT WRITE ON THIS PAGE / ANSWER IN THE SPACES PROVIDED
p27–p28   Additional page（横线是图片）
```

### 2.2 7127（10 卷，32–40 页）

同骨架，差异：题面套方框、字体 AQAChevinPro、Section A 11 题、Section B/C 各 3 题、卷尾插入页更多（最多 6 页）。

### 2.3 共用锚点（两套完全一致，这点很省事）

| 元素 | 实测坐标 | 判定方式 |
|---|---|---|
| 题号徽章 | x0 = 52.4，y ≈ 66 / 300 等 | 粗体，拆成两个独立 span（`0` x=52.4 + `1` x=68.9），字号 11 |
| 小问号 | `. 1` x0 = 82.8，与徽章**同一行同 y** | 粗体，正则 `^\.\s*\d{1,2}$` |
| 分值 | `[7 marks]` 行内，右对齐 x1≈537 | 正则 `\[\s*(\d{1,2})\s*marks?\s*\]` |
| 节标题 | `Section B` y≈63.8 居中 + `Answer all questions in this section.` | 正则 `^Section\s+([A-C])$` |
| 版心 | 页框竖线 39.2–39.7 / 538.6–539.0，正文最右 535.6 | 取 L=40.5、R=537.5、T=55、B=763 |
| 卷尾 | `DO NOT WRITE ON THIS PAGE` / `Additional page, if required` | 整页跳过 |

**没有** `END OF QUESTIONS` 之外的收尾锚点，**没有** `(Total for Question N = X marks)`（那是 Edexcel 会计的命根子）。所以题界只能靠「下一题徽章首次出现」定。

## 3 题级定界

```
题 n 起点 = 徽章 n 的首次出现（按页、y 升序；续页重印的徽章忽略）
题 n 终点 = 题 n+1 起点 y − 3pt
最后一题   = 卷尾插入页（DO NOT WRITE / Additional page）之前
```

两条必须补的规则：

1. **Section 头归下一节第一题**：`Section B` + `Answer all questions…` 在 Q13 上方，若不处理会落到 Q12 尾巴上（实测踩到，见 §5 图 2 底部）。
2. **跨页重印徽章要剔除**：Q13 在 p10 起、p11 顶部又印一遍 `1 3`，题图里会出现两个题号。同题非首段的徽章行直接从 region 里挖掉。

## 4 核心：答题区怎么剥掉

### 4.1 先说不能怎么做

会计题的作答区**不是空的**。举个实测例子（2025-june U1 Q12，p9）：

```
Trial Balance at 31 January 2025
┌──────────────────────────────┬─────┬─────┐
│ Account                      │ Dr  │ Cr  │   ← 表头，学生看格式
├──────────────────────────────┼─────┼─────┤
│ Cash at bank                 │     │     │   ← 科目名已印，只留空给金额
│ Depreciation expense         │     │     │
│ … 共 12 行                                │
└──────────────────────────────┴─────┴─────┘
```

再看 7127 Q14.1 的固定资产明细表，作答区里印着 `At 1 April 2019` / `Depreciation` / `Net book value` / `At 31 March 2020` —— 这些是**答题骨架**，删了题目就残缺。

> 所以「不保留答题区」不能理解成「把小问之间的东西全删」。正确尺度是：**只删没有字的行带**。

### 4.2 算法（已实现验证，`_tmp/dryrun_aqa_acct.py`）

对每题区间的每一页：

1. 收集**横线**：`drawings` 里 `width ≥ 60pt` 且 `height < 2pt` 且在版心内的横条。
2. **规则 ①（横线夹层）**：相邻两条横线之间若**没有任何文字行的中心**，整条带删掉（含线本身）。相邻删除带间隔 < 2pt 时合并 —— 否则 21 条作答横线会压成一条黑条。单条带宽 4–80pt 才参与。
3. **规则 ②（纯空白）**：无文字、无横线、无图片的纵向区间 ≥ 40pt → 压到 12pt。
4. **保护**：文字行、图片 bbox、题号徽章、`[N marks]` 行一律不删；删除带不越题界。
5. 剩下的区间按 y 排序 → `regions` 同页多段。渲染层已有「同页多段拼接」逻辑（Edexcel 会计点线压缩在用），**渲染代码零改动**。

### 4.3 实测压缩率

| 卷 | 原总高 | 压缩后 | 比例 | 最长单题 |
|---|---|---|---|---|
| 2025-june U1（9615） | 16 757pt | 7 614pt | **45%** | Q13 1 161pt |
| 2020-oct U1（7127） | 18 853pt | 7 908pt | **42%** | Q15 1 357pt |

整卷文字只占 21–26%，空白 74–79%；每卷作答横线 381–668 条、空表格行 189–419 行。

单题压后普遍 180–1 200pt（≈500–3 300px @200dpi），**WebP 高度上限完全不是问题**。

### 4.4 压完长什么样

Q13（3 页 → 1 张 1 166pt 的图）：

- 材料表格（Cash Book / Bank Statement）完整保留 —— 那是题面；
- `13.1` 的 11 条作答横线全部消失，题面直接接 `13.2`；
- `13.2` 的 Discount Allowed / Discount Received 空表只剩表头行（Date/Details/$），4 行空白删掉；
- `13.3` 的 21 条横线只剩题面 + 12 分标注。

Q12（Trial Balance）只压到 1 013pt，因为 12 行科目名都有字 —— 这是**正确**结果，不是压缩失效。

## 5 产出与入库

### 5.1 产物（与 AQA 化学完全同构）

```
data/aqa/a-level/accounting/2026-june-ac01/
  source.pdf
  cut.json          regions 多段 + subquestions + option_hotzones（MCQ）
  q01.md … q16.md
  assets/q01.webp、q01.layout.json …
```

- `blocks` 只有 `["qp"]`；**不产** `answer_block` / `answer_regions` / `material_regions`。
- 小问 label 用数字串（`"1"`、`"2"`），与化学 `. N` 一致。
- MCQ 走化学那套 `option_hotzones`（A–D 粗体行聚类），Section A 整节判 mcq。
- `section` 字段写 `A` / `B` / `C`。

### 5.2 单元键（这里有个坑，切完入库前必须解决）

- 源有 U1/U2（AS）和 U3/U4（A2），但词表 `data/taxonomy/aqa/a-level/accounting.json` **只有 P1 / P2 两个键**。
- `store.unit_from_paper_code()` 只认 `[PC]H0?(\d)` 和 `1\d`，`ac01` 会落到 `unknown` → 打标被拒。
- 按项目铁律，**三处必须同改**：`store.unit_from_paper_code` + `taxonomy._UNIT_KEY_RE` + `frontend/src/components/TagAdmin.tsx` 的 `UNIT_RE`。

建议：单元键统一成 **U1–U4**（跟化学 U1–U5、Edexcel U1–U6 对齐），把现有 P1/P2 的 27 个组按大纲重分（P1 里混了「预算 / 盈亏平衡 / 边际成本」三个本该属 P2 的组）。会计词表还没上线、零引用，现在改成本最低。

## 7 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 7127 与 9615 混库 | 考点/分值结构错乱 | 见 §9 决策① |
| 表格竖线在删除带处断开 | 表格看着「缺行」 | 删除带按「横线到横线」取整，拼接后竖线同 x 对齐；视觉抽检确认 |
| 分数线 / 下划线被误判为作答横线 | 题面被切 | 只认 `width ≥ 60pt` 的横线；短分数线不参与 |
| 材料方框右边线切出竖线残段 | 图右边缘有杂线 | L/R 收到 40.5 / 537.5，实测页框线 39.2 / 538.6 |
| 句末 `Turn over for the next question` 残留 | 题图尾部吊一行导航 | 导航行不计入内容、题尾自动裁掉 |
| 7127 卷尾插入页多达 6 页 | 题尾吞进空白页 | 卷尾硬界按 `DO NOT WRITE` / `Additional page` 首现页截断 |

## 9 待拍板

**① 那 10 卷 7127 切不切？**

- **A（推荐）**：只切 6 卷 9615（96 题）。干净，跟词表口径一致；7127 另开一场讨论。
- **B**：16 卷全切（266 题），7127 在题目元数据里打标（但路径结构 `board/qual/subject` 没有维度放这个区分，只能写进 `paper_code`）。
- **C**：7127 单独建学科目录（如 `accounting-uk`），会污染学科列表。

**② 压缩力度选哪档？**

- **A（推荐）**：删干净，删除带不留间距（实测 45%）。表格只剩有字的行，像正常表格。
- **B**：每个删除带留 12pt 呼吸位（整卷约 60%），小问之间不贴脸。
- **C**：只删纯空白，保留作答横线与空表格（≈85%），基本等于不压。

**③ U3/U4（A2，2 卷）现在切还是等词表补齐？**

- **A（推荐）**：一起切。切割不依赖词表，打标等词表好再说。
- **B**：先切 U1/U2 四卷，U3/U4 押后。
