## 二、定位：契约包

一句话：**他们怎么写脚本我不管，但产物必须过同一把尺子。**

```
         ┌──────────────────────────────────────┐
         │  他们 + 他们的 AI                      │
         │  读底本 → 探测 → 写脚本 → 切卷          │
         └───────────────┬──────────────────────┘
                         ▼
    ┌────────────────────────────────────────────┐
    │  ② 契约   产物长什么样（人读 + 机器读）       │
    │  ③ 判据   机器说行不行（他们切完自己跑）      │
    │  ④ 底本   脚本原文（AI 照这个写）            │
    │  ⑤ 样本   对的什么样 / 错的为什么错          │
    └───────────────┬────────────────────────────┘
                    ▼
         合格 → 攒着；合并时我再跑一遍同一套判据
```

## 四、四根支柱

### 支柱 1 · 契约（不许改）

| 文件 | 管什么 | 最容易踩的 |
|---|---|---|
| `01-产物规格.md` | 一个卷目录里必须有哪 5 样、数量怎么对应 | 漏 `layout.json`、`qNN.md` 与 `cut.json` 题数不一致 |
| `02-cut.json-字段说明.md` | 逐字段必填/类型/含义 | `additionalProperties: false`，多写个 `marks_sum` 直接被拒（真踩过）；`number` 必须是 **string** |
| `03-qNN.md-front-matter.md` | 字段表 + 状态同步 | `cut_status` 不同步 → validate 第 6 项失败 |
| `04-layout.json-坐标口径.md` | 归一化 0–1、pt 左上原点、y 向下、px = pt×DPI÷72 | 口径错一位，热区全歪，**schema 查不出来** |
| `05-命名与目录规则.md` | `<board>/<qual>/<subject>/<year>-<session>-<code>`、`qNN` 两位补零 | 路径即分类，错了索引就废 |

硬规矩写进 README 第一屏：**要加字段先提，我改 schema 再全库重建；不许在自己的产物里自创字段。**

### 支柱 2 · 判据（他们切完自己跑）

| 工具 | 查什么 | 什么时候跑 |
|---|---|---|
| `doctor.py` | Python 版本 / 三个依赖 / 能否读 PDF / schema 齐全 | 装完环境一次 |
| `validate_cut.py` | schema / sha256 / 题号连续 / 区域重叠 / 分值合计 / status 同步 / layout 对齐 | 每卷 |
| `audit_cut_edges.py` | **画面**切坏：某行字或横线被切成两半 | 每卷 |
| `contract_check.py` | **与现有库同构**（见下表） | 每卷 |
| `checklist.py` | 把上面三个串起来，输出一句人话结论 | 每卷，日常就用这个 |

`contract_check.py` 是这轮最要紧的新东西，直接对应「保证产物逻辑与我现有的匹配」：

| 检查项 | 判定方式 |
|---|---|
| 文件齐全 | 5 类文件逐个存在，`qNN.webp` 与 `qNN.layout.json` 必须成对 |
| 数量对齐 | `cut.json` 题数 == `qNN.md` 数 == webp 数 == layout 数 |
| 题号规范 | 连续 1..N、两位补零、`number` 是 string |
| 键集合 | 三份文件的顶层键，与基线 1368 卷的键集合比对，多一个少一个都报 |
| 图片规格 | WebP 格式、单边 ≤ 上限、DPI 与 `cut.json` 的 render 记录一致 |
| 坐标合法 | layout 全部 0–1；`segs` 每段有 `kind`；`pt` / `img` 是 2 元不是 4 元 bbox |
| 分值闭合 | 各题 `total_marks` 之和 == `paper.md` 的 `total_marks` |
| 命名合规 | session 三段式；board/qual/subject 在已知枚举内 |

> 双时机：**他们切完跑**（立刻发现问题，不用等我）→ **合并时我再跑**（同一份脚本，结果可复现）。不做两个版本，避免口径漂移。

### 支柱 3 · 代码底本（v4 新增）

这是你要求的「脚本原文」。但**给原文不是目的，让 AI 抄对才是目的**。

`脚本地图.md` 每份脚本一行，三类标注：

| 标注 | 含义 |
|---|---|
| 可直接跑 | 现有 A-Level 卷仍能跑，可用来验证环境 |
| 只能读不能跑 | 依赖特定目录结构或未入库数据 |
| 抄这里 | 明确指出「写新版式脚本时要抄哪一段」 |

示例（节选）：

| 脚本 | 作用 | 定位 | AI 写新脚本时抄哪段 |
|---|---|---|---|
| `cut_paper.py` | Edexcel 理化生 | 可直接跑 | 题号 + `(Total for Question N = X marks)` 双锚点配对；答题册检测 |
| `cut_paper_cie.py` | CIE 9702 | 可直接跑 | `[Total: N]` 右对齐锚点收界；乱码 span 位移还原 |
| `cut_paper_aqa_chem.py` | 牛津 AQA 化学 | 可直接跑 | 徽章 `0 N` 序列取首次；页尾封顶裁剪 `CAP=120pt` |
| `render_questions.py` | 题图渲染 | 可直接跑 | 跨页多 region 纵向拼接；layout 归一化换算 |
| `validate_cut.py` | 结构校验 | 可直接跑 | schema 校验写法 + 10 项检查的判据 |
| `audit_cut_edges.py` | 边界体检 | 可直接跑 | 文本行/图形跨边界的判据 |

`怎么让 AI 读这些脚本.md` 是这一块的关键，核心是**别把全文贴给 AI**——那样它只学到字面，学不到为什么：

1. 先让 AI 读**同考试局、同学科**的现有脚本（写 Edexcel IGCSE 物理 → 读 `cut_paper.py`），别跨局乱读
2. 再让它读 `01-契约/` 里的 schema
3. **先要探测报告，不要代码**：让它只读 PDF，报出页面尺寸、题号形态与 x 坐标、分值锚点形态、页尾与附录页位置
4. 我确认探测报告合理，再让它写
5. 写完必跑 `checklist.py`，不过不许往下切下一卷

附三条红线：不许改 schema；不许改 `validate_cut.py` 的判据；不许在产物里加自创字段。

`已知缺陷与待改点.md` 要如实写：`batch_run.py` 里写死了本机 venv 路径、`import_aqa.py` 头部示例路径、已知限制清单（数学式碎成单字符、扫描卷需 OCR 等）。这些我打包前会改掉两处路径，但仍要在文档里标出来，免得他们抄进自己的脚本。

### 支柱 4 · 样本

| 内容 | 说明 |
|---|---|
| `samples/` | 每类版式一份完正产物，带 `source.pdf`（`cut.json` 记 sha256，不带则验收永远跑不过） |
| `_读样本的五个地方.md` | 拿到样本先看哪 5 处，10 分钟看懂「切得好」是什么样 |
| `反例/` | 2–3 份刻意保留的错误产物 + 一句话说明错在哪一行。**比十条规则管用** |

样本按**版式类型**出，不按目标科目出（科目由他们定）：Edexcel 理化生 3 + 数学 1 + 会计 1 + 经济 1 + AQA 2 + CIE 3，加 5 份特殊卷型（中国区 01A 合并卷 / 会计三册 / A4 版式 / 跨页长题 / 附录表同页）。约 40MB。

## 五、IGCSE 版式探测记录（已实测，直接进包）

| 组合 | 页面 | 题界锚点 | 关键坑 |
|---|---|---|---|
| CAIE 数学 0580 | Letter 612×792 | **无 Total 行**；题号单行粗体 x≈72.4 + 行内 `[N]` 右对齐 x≈516 | 收界只能靠题号序列 + `[Turn over` 位置，误判风险高 |
| Edexcel 数学 4MA1 | **A4 595×842** | `(Total for Question N is X marks)`，实测 25 处 | 第 2 页是公式表，必须整页跳过，否则题 1 会把公式表裁进来 |
| Edexcel 经济 4EC1 | A4 595×842 | `(Total for Question N = X marks)`，4 处 | 题号行带 tab（`1\t(a)\t`）；`DO NOT WRITE` 竖排栏在 x≈570 |

另附事实：`data/` 里零 IGCSE 卷；`downloadPapers/` 里 IGCSE 只有这 4 个组合（含 AQA 数学 9260 的 4 份 specimen），**物理/化学/生物零源卷**。

## 六、产物保管与合并

- **现阶段**：产物由他们保管，不往我这边传。每卷切完自己跑 `checklist.py`，结论记在自己的清单里。
- **合并时**：按 `06-协作/产物保管与合并.md` 的格式打包（只带 `cut.json` + `paper.md` + `qNN.md` + `assets/`，**不带 PDF**，体积原因），命名 `<卷目录名>.zip`。
- 合并前我这边跑同一套判据（`validate` + `audit` + `contract_check`），不一致的原样退回，附具体哪一项不过。
