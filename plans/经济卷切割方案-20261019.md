**与会计最大的不同**（您已指出）：三段顺序是 **题面 → 资料 → 作答区**；会计是 资料 → 题面 → 作答区。

**本次不切作答区**，所以题图只有两段：**题面（→ 资料）**。三段顺序这件事仍要处理——资料块拼在题面**之后**，渲染层要加开关。

**比会计更干净的地方**：资料册只服务**一道题**（WEC11/12 → Q12；WEC13/14 → Q7），靠 `Study Figure 1 and Extracts … before answering Question N` 就能锚定。

## 2 实测的三种版式

### 2.1 A 型：普通国际卷（80 份，单遍）

以 `2025-june-wec11`（32 页）为例：

| 页 | 内容 |
|---|---|
| p1 | 封面（`Source Booklet (enclosed)`） |
| p2–p6 | Section A（选择题，无点线） |
| p7–p11 | Section B（每题一页：题面 + 20 行点线 + Total） |
| p12 | **Section C 五道小问题面集中在这一页**（无点线） |
| p13–p20 | Section C 作答页：(a) 页顶复述小问 + 点线，(b)(c)(d)(e) 各自起新页 |
| p21 | BLANK |
| p22 | Section D：13 / 14 题面 + 各自 Total（无点线） |
| p23–p27 | Section D 通用作答区（5 页点线） |
| p28 | BLANK |
| p29–p32 | **Source Booklet**（Figure 1 + Extract A/B/C + 引文页） |

### 2.2 B 型：01A 中国区卷（12 份，两遍）

以 `2026-jan-wec11a`（36 页）为例：

| 段 | 页 | 内容 | 标识 |
|---|---|---|---|
| ① QP（紧凑版） | p1–p8 | 只有题面，**完全没有点线** | 无竖排边栏 |
| ② Source Booklet | p9–p12 | Figure / Extract | 标题页只有一行 `Source Booklet` |
| ③ Answer Booklet | p13–p36 | 只有 `Question 12(a)` + 分值 + 点线 | 二次封面 `Please check the examination details` |

> B 型的题面段直接就是整段 QP，切起来最简单——本次不要作答区，第三段整段用不上。

### 2.3 C 型：混合版（1 份，`2025-june-wec14a`）

Section B 的作答区内联在题面后、Section C 的作答区是通用答题册。按"段"而不是按"卷"处理即可。

### 2.4 版式自动判定

| 特征 | 判定 |
|---|---|
| 整页只有一行 `Source Booklet`，且不是第 1 页 | 资料段起点 |
| 资料段之后出现第二张 `Please check the examination details` 封面 | 答题册段起点（本次不用） |
| `(Total for Question N …)` 在卷内出现 1 次 / 2 次 | 单遍 / 两遍 |

实测：93 份全部能找到且只找到一个资料册标题页。

> ⚠️ `2024.1/wec13` 的封面页也含单独一行 `Source Booklet`，必须跳过第 1 页。

## 3 一题一图怎么拼

| 题型 | 组成 | 顺序 |
|---|---|---|
| Section A 选择题 | 题面 + 选项 A–D（含图表），**不带 SECTION A 头** | 单段 |
| Section B 短答（WEC11/12 Q7–11） | 题面（点线裁掉），不带 SECTION B 头 | 单段 |
| **带资料的大题**（WEC11/12 Q12、WEC13/14 Q7） | SECTION 头（含 Study 指引）+ 题面段 + 资料段 | **题面 → 资料** |
| Section D 二选一（13/14） | 只切题面，**不带 SECTION D 头、不带 EITHER / OR** | 单段 |
| Section C 三选二（8/9/10） | 只切题面，不带 SECTION C 头 | 单段 |
| 01A 全题型 | 紧凑题面（+ 资料）；仅 Section C/B 连带 SECTION 头 | **题面 → 资料** |

`cut.json` 复用会计那套字段：`regions` = 题面，`material_regions` = 资料；**不用** `answer_block` / `answer_regions`。
**新增 `material_order: "after"`**（默认 `"before"` 保持会计/理化不受影响），渲染层据此决定拼接顺序与提示文字：

- 会计式：`本题依次为：资料（Source Booklet）→ 题面 → 作答区`
- 经济式：`本题依次为：题面 → 资料（Source Booklet）`

## 4 锚点与边界规则

| 边界 | 规则 |
|---|---|
| 题起点 | 该题题号行（粗体、左缘 x≈42、`N\t…` 或独立 `N`） |
| **SECTION 头裁留** | 本节首题才可能连带 SECTION 头，判据是**头块里有没有 `Study … in the Source Booklet before answering Question N`**（2026-10-19 王培琪定）：<br>· **有 → 连带**（WEC11/12 的 SECTION C、WEC13/14 的 SECTION B，这句是答题必需指引）<br>· **无 → 整块丢掉**（SECTION A / B / C(13,14) / **D** 只剩 `Answer ONE question…`、`Write your answer in the space provided.`、`EITHER` 这类纯版式说明；题卡头已显示 Section 字段，图里再留一遍是噪音） |
| 备选题起点 | 一律从**自己的题号行**起。13/14 之间的 `OR` 不并入任何一题（原先「Q14 从 OR 行起」的做法 2026-10-19 已废） |
| 题终点 | 先按 `(Total for Question N = X marks)` 行下沿 + 2pt；若正好横穿 Total 下方那条分隔横线，推至线底 + 2pt（否则渲染出半条灰线，看着像字被切） |
| 缺 Total 兜底 | **实测没有缺**：`2023-oct-wec11` 的 Q10 印成 `Total for Question 10 = 4 marks)`（少了行首的 `(`），`cut_paper.py` 的 `TOTAL_RE` 已容错。脚本仍保留「下一题起点定界」的兜底分支 |
| 资料段归属 | 优先解析 `before answering Question N`；21 份卷没有这句 → 按单元固定规则（WEC11/12 → Q12，WEC13/14 → Q7） |
| 资料段终点 | 下一个段起点前一页；段尾 `BLANK PAGE` 由 `trim_regions_trailing_blank` 裁 |
| **作答页判定** | 页首（y0 < 200）是重复的小问标签行，或整页只有点线 → **整页丢弃**（WEC11 Q12 的 p13–p20、WEC13 Q7 的 p7–p13） |
| **页内点线** | 起点页里从第一行点线往下全裁（Section B 的 4 分题：题面 3 行，点线和 Total 行一起去掉） |
| 版心 | L 39 / T 40 / R 556 / B 788（页框 35–560.3，内容 x 42.2–552.8） |

> 裁掉点线后的直接影响：**Section B 的 4 分小题会变成 3–4 行的短条**（约 1650×360 px）。这是"只题面"的必然结果。若想给它留一点画图空间，把"从第一行点线全裁"改成"保留前 12 行点线"即可——一个参数的事。

## 7 三个必须解决的问题

### 7.1 图高——本次不再是问题

不切作答区之后，最长的题是 Q12：

| 题 | 段构成 | 高度 | 200 DPI 像素 |
|---|---|---|---|
| WEC11 Q12（A 型） | 题面 1 页 + 资料 3 页 | ≈3000 pt | ≈8 300 px ✅ |
| WEC11 Q12（B 型） | 题面 1 页 + 资料 3 页 | ≈3000 pt | ≈8 300 px ✅ |
| WEC13 Q7 | 题面 1 页 + 资料 3 页 | ≈3000 pt | ≈8 300 px ✅ |

WebP 单边上限 16320 px，余量充足，**不需要点线压缩、不需要降 DPI**。

### 7.2 题号起点误判

选择题页里满是数字（年份、坐标轴刻度、表格数据）。沿用 `cut_paper.py` 三条约束（粗体 / x0 < 100 / 序列递增早于下一题首个候选），再加一条硬校验：**起点之后必须有本题的 Total 锚点**，否则回落上一题 Total 之下的第一行。

### 7.3 共享作答区无法归属 → 已拍板

WEC11/12 的 13/14 共用 p23–p27；WEC13/14 的 8/9/10 共用两段通用区。卷面只让学生自己打叉"我答的是第几题"，**不绑定题号**。既然本次不切作答区，这三题天然只剩题面。

## 9 验收方式

1. **题数与分值**：WEC11/12 每题号唯一、分值合计 100（13/14 各 20 都计）；WEC13/14 同理
2. **题面段与资料段不重叠**，且一份卷里只有**一个**题挂 `material_regions`
3. **抽检图**：每卷随机 2 题，生成 HTML 对照页（左：原卷页；右：题图）人工翻
4. `audit_cut_edges.py` 必跑（边界压字检测）
5. `validate_cut.py` 必跑（schema / sha256 / 题号连续 / MCQ 热区 A–D）

## 11 全量过程中踩到的四个坑（已在脚本里修掉）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 资料页底边把图表 x 轴的年份切成两半（2021-june-wec14 Q7，19 处） | 年份标签是**旋转文字**，`build_page_lines` 跳过 `dir != (1,0)`，算 last_y 时漏掉 | `trim_all`/`trim_top` 补一遍 `get_text("words")` 词框（旋转与否一并兜住） |
| 2 | Q7 的题面段把整张作答页吞进来（2756pt / 7656px） | 作答页首行是**题干续尾**（"In 2018, the EU's rate of inflation was 1.6%."）而不是小问标签，`is_answer_page` 的「页首是标签行」判据失效 | 判据改为以「该页有 ≥3 行点线」为主 |
| 3 | 2019-june / 2019-oct 三卷右侧内容被切（"Quantity of education" → "educat"） | 这三卷是 **652×899** 页面，而版心写死 595×842 的 L39/R556 | `set_geom()` 按卷自适应：A4 走原值；非 A4 按**实测页脚行**推 footer/B，右沿避开右侧边栏 |
| 4 | 652 版式左侧露出半截竖排 "DO NOT WRITE IN THIS AREA" | 边栏框（x≈41.6–50）压在版心内，与题号行在 x 上重叠、只在 y 上错开，矩形切割分不开 | 渲染层 `_mask_sidebars()` 把贴页边的窄高竖条涂白（仅对 `pw ≥ 620` 的卷启用） |
