## 2. 为什么必须另写一份脚本

`cut_paper.py` 是给理化用的：题干与作答区是**两本册子**，切割 = 在 QP 里找 "N (a)" 起点 + "(Total for Question N = X marks)" 终点。

数学完全不同：

1. **作答区就在题面里** —— 题干 → 一片答题横线 → 下一小问题干 → 再一片 → … → Total 行。
   所以"一题"不是一段连续矩形，而是**若干段内容块**；一题的 regions 天然多条。
   渲染层本来就支持多段纵向拼接、同页两段之间自动画浅灰接缝线，正好接得上。
2. **两代版式差很多**：

| | 2020-jan – 2022-oct（77 卷） | 2023-jan – 2026-june（188 卷） |
|---|---|---|
| 题尾锚点 | `(Total 6 marks)` 无题号，只能靠"下一题起点"兜底 | `(Total for Question 1 is 6 marks)` |
| 角标 | 右上角 `Leave blank` 方框 + 右下角 `Qn` 框 | 无 |
| 续页 | 页顶 `Question N continued` | 同 |
| 小问标签 | `(a)␉ …` 独立行 | 常与作答行粘连成 `(a)______` |
| 页码错字 | 有 `3..`（两个点，2020 WMA12 实测） | 无 |

## 3. 切割规则（只切问题）

新增 `scripts/cut_paper_math.py`（复用 `cut_paper.py` 的底层行/图形解析，不复制副本）。

- **起点**：`^N.`/`^N..` 顶格行（x≤75pt），按 1,2,3… 序列推进（粗体优先、非粗体补位）。
- **终点**：本题带号 Total 行 → 旧版无号 Total 行 → 下一题起点 / 末内容行。
- **剔除（即作答区）**
  - 整行下划线作答行；`(a)____` 标签粘连行；
  - **整页作答页**：无题号 + 正文量 <60 字符 + （≥8 行作答线 或 `Copy of Diagram N` / `Only use this copy…` 样板）→ 整页文本与图形剔除，只留 Total 行；
  - 页脚（页码/条码/Turn over/角标）、左右竖排 `DO NOT WRITE IN THIS AREA`、整页装饰框（35–560.3）、出血图（x 越界）。
- **保留**：题干、公式、表格、坐标图、`Figure N`/`Diagram N` 图注、右对齐分值行 `(3)`、Total 行、小问标签。
- **跨页 / 跨作答区**：被剔除的作答行处断成新段，渲染时纵向拼接 + 浅灰接缝线。
- **01A 合并卷**：按页脚条码族（`PxxxxxA`）识别答题册起点，只切 QP 的 8 页。
- 版心固定 **L=40 / R=556**，避开装饰框与右下角角标。
- 渲染层补 `_mask_corner_label()`：按词框涂白旧卷右上角 `Leave blank`（切割层剔不掉——题号行就在同一高度）。
