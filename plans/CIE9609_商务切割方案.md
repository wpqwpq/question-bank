> 分值 `[8]` **印在最后一条点线的尾巴上**（和点线同一个 span），这是最容易丢的东西。

## 二、切割口径

1. **题图 = 资料在前、题面在后**，`cut.json` 写 `material_order = "before"`。
2. **点线作答区全部裁掉**：页内按「连续点线块」把一页切成若干带，只留带内正文；
   同页相邻两带之间画一条浅灰细线当接缝（告诉读者这里删掉了一段）。
3. **分值 `[n]` 单独留成右对齐窄条**：只取 `[` 那一小段（不含点线），标 `align:"right"`，
   渲染时贴题图右沿 —— 位置跟真卷一致，也不带一丁点答题线。
4. Section 字头（`Section A`）、`Answer all questions`、`You are advised to spend…`
   一律丢弃并当断点；`EITHER`/`OR` 只当断点丢弃（选做关系已在题数/总分上讲清）。
5. 表格框线、图表、网络图随带外扩，不能只按最后一行文字收（会削掉底框）。
6. 小问只记锚点不产子图（CIE 在云端子图黑名单里）。
7. 选做卷（P1 全季、P3 2020–2022）`paper.md` **不写 `total_marks`**，改写
   `printed_total_marks` —— 逐题分值加起来必然大于印刷总分。

## 三、各卷型的资料怎么来

| 卷型 | 资料范围 | 归属 |
|---|---|---|
| P1 | 无 | — |
| P2 | 该题自己的 case：从题号行（与 case 标题同行）到第一个小问 `(a)` 之前 | **每题一份，各不同** |
| P3 | INSERT 全册正文：跳过封面、`BLANK PAGE`、版权页 | **全卷共用一份，拼在每题之前** |
| P4 | QP 内 p2 起至「Answer both questions.」之前的 case + Appendix | **全卷共用一份，拼在每题之前** |

P3 的 INSERT 在 `prep` 阶段就接进 `source.pdf` 尾部（`paper.md` 记 `insert_start_page`），
渲染器只读一个 PDF，`page` 是文件内绝对页号。

## 四、五个必踩的坑（都已修）

1. **页脚测量**：封面 `© UCLES` 在 y≈777，比内页低 20pt；INSERT 页脚又比 QP 高一截。
   混着测会把正文底界拽到 775，末题最后一行连同分值条一起被砍。→ 只测 QP 内页。
2. **左侧竖排 `DO NOT WRITE IN THIS MARGIN` / 条形码数字串**（x≈18–28、竖向拉得很长）
   会把版心左界拽到 24。→ 按「高>25pt 且宽<40pt」排除。
3. **末页版权段落**首行是 `Cambridge Assessment International Education is part of…`，
   宽写成 `^Camb` 会误当页脚。→ 只认 `^© UCLES` / `^卷号`。
4. **P2 的重复**：题号行与 case 标题同一行，若「资料」和「题面」都从题号行起算，
   case 会整段出现两遍。→ 题面从第一个小问起算。
5. **分值条**：见口径第 3 条，否则 P3 所有题的 `total_marks` 全是 None。

## 六、材料归属核查（135 卷全量跑过，2026-10-22）

「资料对应哪道题」不是靠看出来的，是**按版式结构定位** + 全量机器核查：

| 卷型 | 归属方式 | 为什么可靠 |
|---|---|---|
| P1 | 无资料 | — |
| P2 | 从该题的题号行（与 case 标题**同一行**、印在页顶）切到**该题第一个小问 `(a)` 之前** | 按 y 轴区间切，不做「找标题」的模糊匹配；题号行本身就是 case 的起点 |
| P3 | INSERT **整册正文**拼给每题 | 已核实 39 份 INSERT 全是**一份 case 走全卷**，没有 `Question N` / `Source X for Question N` 这种分题结构（只有 3 处 `See Question 2(a)(i)` 这类表内交叉引用） |
| P4 | QP 内 p2 起、到「Answer both questions.」之前的 case + Appendix 全部 | 题目固定在附录之后，用「第一题题号」当终止锚点，不靠猜 |

全量核查结果（131 份可读卷 / 588 题 / 326 题带资料）：

- **题干混进资料：0 处**（取每题正文前 45 个字符做全文匹配）；
- **P2 材料与「(a)」的纵距：全部 < 60pt**，且题面正文 100% 以 `(a)` 开头；
- **P4 的 Appendix：全部落在资料里，0 处跑到题面里**；
- **材料页号：0 处乱序**；
- P3 各题材料一致性：同卷内所有题拿到的材料文本完全相同（本来就是全卷共用）。

抽证（5 卷试切逐题对照，资料首句 vs 题干）：

| 卷 | 资料首句 | 题干里的公司 |
|---|---|---|
| 2020-june-qp31 | Jan Guiding Service (JGS) | Q1–Q7 全部 JGS ✔ |
| 2023-oct-qp31 | ColorPaints (CP) | Q1–Q5 全部 CP ✔ |
| 2024-june-qp21 | Q1 = `1 Samira's Whiteboards (SW)`；Q2 = `2 Fizzy Drinks (FD)` | 各题对应各自 case ✔ |
| 2025-june-qp41 | Riki's Restaurant (RR) | Q1、Q2 都是 RR ✔ |

> 这一轮核查还揪出两个**会让整卷静默变 0 题**的坑（已修）：
> ① 2024-oct 起部分卷题号丢字重（`bold=False`）→ 题号识别要认「整行纯数字」；
> ② 2025 版（612×792）题号在 y≈59，而页码到 y≈47，`region_top` 若照抄 60 会把题号整批滤掉。
> 现在 `cut_paper_cie_busi.py` 遇到 0 题会直接报错退出，不写空卷。
