# Edexcel IAL 会计卷（WAC11 / WAC12）切割方案

> 2026-10-19 · 对 `downloadPapers/Edexcel_ALevel_Accounting` 全部 60 份 `que` PDF 逐页实测后的方案。四项关键决策已于 09:10 拍板，见 §9。

---

## 0 结论先行

| 项 | 实测结果 |
|---|---|
| 卷数 | 60 份 `que` PDF（54 份国际卷 + 6 份 01A 中国区卷），其中旧大纲 WAC02 不收 → **本次入库 59 卷** |
| 考试季 | 27 个（2017-01 → 2026-06） |
| 每题数量 | 每卷 6 题（旧大纲 WAC02 为 7 题）→ 共 **354 题** |
| 单元 | WAC11 = UNIT 1 The Accounting System and Costing；WAC12 = UNIT 2 Corporate and Management Accounting |
| 卷面总分 | Section A 两题必做（55 + 55 = 110）+ Section B 四选三（每题 30，计 90）= **200 分** |

**最重要的发现**：每道题在卷内不是"出现一次"，而是以同一个 `(Total for Question N = X marks)` 收尾出现 **2 次或 3 次**，而且每次的分值必须相同。这行就是天然的切割锚点和交叉校验——比物理/化学卷还干净。

## 1 实测的两种版式

### 1.1 普通国际卷（54 份）—— 两块

以 `2026-jan-wac11`（48 页）为例：

| 块 | 页范围 | 内容 | 标识 |
|---|---|---|---|
| ① Question Paper | p1–p32 | 题面 + **点线作答区**（逐小问交错排列） | 页右侧竖排 `DO NOT WRITE IN THIS AREA` |
| ② Source Booklet | p33–p48 | 封面 + 各题资料（资产负债表/试算表/附加信息 + Required 清单） | 无竖排边栏，页码从 2 重新起算 |

题级切点（Total 锚点页）：

```
Q1  QP p2–7   资料 p34–35     8 页
Q2  QP p8–13  资料 p36–37     8 页
Q3  QP p14–17 资料 p38–39     6 页
Q4  QP p18–21 资料 p40–41     6 页
Q5  QP p22–26 资料 p42–43     7 页
Q6  QP p27–32 资料 p44–45     8 页
```

> 注意：**题目和答题区在 QP 里是交错的**（"(a) Prepare…(20)" 紧跟 20 行点线，翻页再 "(b)(i)…(5)" 又跟 20 行点线），不是"题目一坨、答题区一坨"。强行拆开会让题面与作答区失去一一对应。

### 1.2 01A 中国区卷（6 份）—— 三块，正好是您说的三部分

以 `2026-jan-wac11a`（60 页）为例：

| 块 | 页范围 | 内容 | 标识 |
|---|---|---|---|
| ① Question Paper（紧凑版） | p1–p8 | **只有题面**，无作答空间，一题一页 | 无竖排边栏 |
| ② Source Booklet | p9–p24 | 资料 + Required | 封面页写 `Source Booklet` |
| ③ Answer Booklet | p25–p60 | 只有 `(a)(i)` 标签 + 分值 + 点线，**没有题面文字** | 竖排边栏回归，卷号变成另一个 P 号 |

题级切点：

```
Q1  QP p2   资料 p10–12  答题册 p22–33   共 16 页   ← 最大的一题
Q2  QP p3   资料 p13–15  答题册 p34–40   共  9 页
Q3  QP p4   资料 p16–17  答题册 p41–45   共  6 页
Q4  QP p5   资料 p18–19  答题册 p46–50   共  6 页
Q5  QP p6   资料 p20–21  答题册 p51–55   共  6 页
Q6  QP p7   资料 p22–23  答题册 p56–59   共  5 页
```

> 01A 的答题册**不复述题面**，所以三块缺一不可：只给资料+答题册，学生不知道要算什么。

### 1.3 版式家族判定（自动）

| 特征 | 判定 |
|---|---|
| `(Total for Question` 出现 2 次/题 | 普通卷（两块） |
| 出现 3 次/题 | 01A（三块） |
| 出现次数按题不等 / 7 题 | 旧大纲 WAC02，单独处理 |

实测 54 份普通卷全为 2 次、6 份 01A 全为 3 次，与文件名 `01a` 完全吻合——双保险。

## 2 一题一图怎么拼

| 版式 | 顺序 | 组成 |
|---|---|---|
| 普通卷 | 资料 → 题目+答题区 | `material_regions`（Source Booklet 该题全页）+ `regions`（QP 该题全页，题面与点线原样保留） |
| 01A | 资料 → 题目 → 答题区 | `material_regions` + `regions`（紧凑 QP）+ `answer_block`（答题册该题，题号行 → Total 行） |

两块之间画一条浅灰分隔线（沿用现在理化卷的做法），题图顶部加一行中文提示，例如：
`以下为本题资料（Source Booklet）` / `以下为题面与作答区`。

`cut.json` 复用现有字段，只新增一个 `material_regions`（数组，语义 = 资料块），`regions` 保持"题目"，`answer_block` 保持"答题区"——渲染器和前端都不必改语义。

## 3 锚点与边界规则

| 边界 | 规则 |
|---|---|
| 资料块起 | Source Booklet 内该题的题号行（粗体 `N` + 正文），若同页有 `SECTION A/B` 头则连带 |
| 资料块止 | 该题第二次（01A 为第二块内）Total 行下沿 + 2pt |
| 题目块起 | QP 内该题题号行（粗体，左缘 x≈42，格式 `N\t(a)\t…` 或独立 `N`） |
| 题目块止 | 该题首次 Total 行下沿 + 2pt |
| 答题块起 | 01A 第三块内该题题号行 |
| 答题块止 | 01A 第三块内该题 Total 行下沿 + 2pt |
| BLANK PAGE | 落在块内时保留（原卷就是这样），落在块尾时裁掉 |
| 页尾空白 | 沿用现有 `trim_*` 逻辑；但**点线区一律不裁**（那是真实作答空间） |
| 版心 | L≈39、R≈556、T≈40、B≈788（页框 35–560.3，内容 x 42.2–552.8） |

## 6 三个必须解决的难点

### 6.1 图太高（核心问题）

A4 = 595×842pt，200 DPI 下每页 1653×2339 px。WebP 单边上限 16383 px。

| 版式 | 最大题页数 | 200 DPI 高度 | 结论 |
|---|---|---|---|
| 普通卷 Q1 | 8 页 | 18 700 px | 超限，DPI 需降到约 174（仍清晰） |
| 01A Q1 | 16 页 | 37 400 px | 超限，DPI 要降到约 87（偏糊，不可接受） |

**对策：点线压缩。** 实测作答点线是文本层，严格等距 **28.2pt**（每页 20–26 行）。因为线是完全相同的，可以在两条线之间整段删掉 K 行再把页面上下拼接，视觉上无缝。

- 每个小问的作答区保留前 8 行点线（约 226pt ≈ A4 的 27%），其余删掉，接缝处画一条浅灰横线 + "⋯ 作答空间已压缩 ⋯"
- 01A Q1：16 页 → 约 7 页（200 DPI 下 16 400 px，刚好），或降到 180 DPI 更稳
- 普通卷 Q1：8 页 → 约 5 页

### 6.2 题号起点误判

实测 `2017-june-wac12` 会把封面/页脚上的独立 `2` 当成 Q2 的起点。对策沿用 `cut_paper.py` 已有的三条约束：粗体、左缘带（x0<100）、序列推进且必须早于下一题首个候选，并加一条新的硬校验——**起点之后必须有本题的 Total 锚点**（会计卷每题必带 Total，比理化卷更可靠）。

### 6.3 资料块内的"Required"与 QP 题面重复

普通卷的资料页末尾自带一份 `Required (a)(b)(i)…` 清单，内容和 QP 的题面几乎一样。建议**保留**（不影响使用，且删它要切页尾容易误伤数据表格）；若要精简，可作为二期的"资料块去 Required"开关。

## 8 验收方式

1. **分值三处一致**：同一题在 QP / 资料 / 答题册的 Total 分值必须相同，脚本自动报错（实测 60 卷全对，可作为基线）
2. **题数与总分**：每题分值合计 = 200；01A 亦为 200
3. **抽检图**：每卷随机 2 题 + 每题首尾各 1 张，生成 HTML 对照页（左：原卷页；右：切出的题图）供人工翻
4. `audit_cut_edges.py` 必跑（边界压字检测）

## 10 对既有数据的影响 & 能否直接在打标台跑（2026-10-19 核查）

### 10.1 对已切割/已上云数据的冲击面

| 项 | 结论 | 依据 |
|---|---|---|
| 物理/化学文件 | **零改动** | 只在 `data/edexcel/a-level/` 下新增 `accounting/` 目录 |
| `paper_id` 冲突 | **不会** | `paper_id_for()` = `board-qual-subject-<会话目录>`，含 subject（10-18 CIE 撞号事件后定的规则） |
| `state.db`（确认/有误） | **不受影响** | state.db 与 index.db 分离；新增卷只在 index 里加行，不写 state |
| `index.db` | 自动增量，无需全量 rebuild | `iter_papers()` 目录扫描 + `_sync_index` 自动发现新卷；即使全量 rebuild 也只是重建"抄件" |
| 上传 | rsync **增量**，不加 `--delete` | 仓库既定纪律 |
| `cut.schema.json` | 加 `material_regions` 属于**放宽**，老 cut.json 依然合法 | `additionalProperties:false` 扩白名单 |
| `render_questions.py`（理化共用） | **风险点**：必须保证「无 material_regions → 走原路径」；理化不重跑则产物一字不变 | 需要重渲前先做输出哈希对拍 |
| `unit_from_paper_code()` | **不用改** | 现正则 `1(\d)`：`WAC11`→U1、`WAC12`→U2，正好命中 |
| `paper_id` 规则 | **绝对不动** | 改它作废全部书签 |

### 10.2 打标台能否直接运行

**能，但要分三层看。**

| 层 | 现状 | 需要做什么 |
|---|---|---|
| ① 看题 / 打标签 / 确认·有误 | 基本可用 | 数据齐 + 词表齐 + 账号学科 + 前端下拉各一项 |
| ②「切分小问」 | 代码已支持该形态 | `render_subsplit` v2 有 `qp_inline`（留白内嵌型）分支，正对会计普通卷；需验证 src_map 多段映射 |
| ③ 上传 / 静态服务 / 云端裁剪 | 不用改 | 云端不跑切割、不跑 render_questions（无 pymupdf），只做 Pillow 裁剪；`/files/` 挂 DATA_DIR |

**① 的四项前置**

1. **词表（内容活，非代码）**：`data/taxonomy/edexcel/a-level/accounting.json` 必须存在，**顶层键必须是 `U1` / `U2`**（`paper.unit()` 决定可选单元）。没有它 → 题能看、右栏标签树为空、标不了。
2. **前端学科下拉（1 行 + build + 覆盖 dist）**：`Sidebar.tsx` 硬编码 `<option value="physics|chemistry|biology|mathematics">`，没有 accounting。不改也能靠 `App.tsx:199` 的兜底（账号 subjects 首个）切过去，但下拉框显示空白。
3. **账号 `subjects`**：需含 `accounting`，否则 `auth.require_subject` 一律 404（admin 与 `*` 不受限）。改 `users.yaml` 后 `store`/`auth` 按 mtime 自动重载，不用重启。
4. **`qNN.md` / `paper.md` 字段**：`question_type: structured`、`total_marks`、`section: A|B`、`image`/`layout` 相对路径正确。

**② 的注意点**

- 普通卷走 `qp_inline`：子图 = 题干段 + 本小问段（含点线），**不含资料块**（资料是整题的）。接受这个取舍，否则要给小问图加资料前缀。
- 01A 必须同时给 `answer_block` **和** `answer_regions`，否则 `degraded=True` → 子图不含作答区并弹警告。
- 点线压缩后，同一页会在 `src_map` 里出现两段（上下各一段）。`SrcMap.y()` 按 `(page, pt)` 顺序匹配、区间不重叠，能正确映射；实现时必须如实写 segs。

**结论**：切割产物打包上云后，「浏览 + 打标签 + 确认」当天就能用；只要先补词表与前端那一行。子题切分要在首卷上实测一遍再批量。
