## 1. 问题是什么

Edexcel 化学 Section A 里有大量「一个题号下 (a)(b)(c) 各带一套 A–D 选项」的选择题（例：2021-06 WCH14 Q4，3 分 = 3 问，每题 1 分）。

现状是三层都卡住：

| 层 | 位置 | 现状 | 根因 |
|---|---|---|---|
| 切割元数据 | `cut.json` 的 `subquestions` | 恒为 `[]` | `cut_paper.py:758` 写死 `if not is_mcq:` 才扫小问标签 |
| 选项热区 | `cut.json` 的 `option_hotzones[].part` | **有**（a/b/c 分组已正确） | 这层反而是好的，可以当交叉校验 |
| 后端 | `api.py:295` | 详情接口对 mcq 直接跳过 `top_labels` → `split_eligible=false` | 硬编码 `!= "mcq"` |
| 后端 | `api.py:511` | 保存切分时 `raise 422 "MCQ 不支持小问切分"` | 硬编码 |
| 裁图 | `render_subsplit.py:156` | `raise "MCQ 无小问结构，不支持切分"` | 硬编码 |
| 前端 | `App.tsx` | 只看 `split_eligible` / `top_labels`，**没有 mcq 分支** | ✅ 无需改 |

即：小问标签其实早就被算法找到了（`_part_label_of()` 就是靠它给选项分组的），只是**没存进 cut.json**，所以下游一路拿不到。

## 3. 可行性验证（已跑，只动临时副本）

### 3.1 小问标签能不能扫回来？

用 `cut_paper.py` 同款解析函数（`parse_subhead` / `parse_bare_subhead` / `get_text("dict")`），在 `source.pdf` 上按现有 `regions` 重扫：

```

标签与 option_hotzones 的 part 完全一致：106/110
```

不一致的 4 题全是**选项热区**的问题，不是小问标签的问题（见 §6）。

### 3.2 补上 subquestions 能不能切？

|---|---|---|---|

| 2025-06 WCH11 | Q14 | a/b（跨页） | 2 张，0 warning |

目视检查：子图 = 题干段（题号 + 图/表，每问都带）+ 本问段（(a) 及其 A–D），末问自动裁掉 `Total for Question` 行。正是打标台里要的样子。

## 4. 推荐方案：只补元数据 + 放开三处硬闸

### 4.1 数据补丁（一次性脚本，增量）

| 文件 | 动作 |
|---|---|
| `cut.json` | 给 110 题写 `subquestions: [{label, page, bbox}]`（label 是 a/b/c…，bbox 是 `(a)` 标签行在 PDF 里的 pt 坐标） |
| `assets/qNN.layout.json` | 同步写 `subquestions`（归一化 box）——**否则 `validate_cut.py` 判「layout 与 cut 不一致」红灯** |
| `assets/qNN.webp` | 不动 |
| `qNN.md` | 不动（不写 `subquestions`，不写 `split`） |
| `regions` / `option_hotzones` / 正文 | 不动 |

要点：
- **幂等**：已有 `subquestions` 的题跳过；写前 `cut.json` 备份成 `cut.json.bak-20261019`。
- **先 dry-run 出报告**（每卷：题号 / 标签 / 是否跨页 / 与 part 是否一致），确认无异常再落盘。
- layout 的 box 需要复算跨页题的段间偏移；算不齐的那几卷，退化为对该卷重跑 `render_questions.py`（**只渲图不重切**，31 卷约 5 分钟）。

### 4.2 代码改动（4 处 + 2 份副本）

| 文件 | 行 | 改动 |
|---|---|---|
| `cloud/workbench/backend/api.py` | 295 | 删掉 `and cut_q.get("question_type") != "mcq"` |
| `cloud/workbench/backend/api.py` | 511-512 | 删掉 mcq 的 422 拦截（`top_labels < 2` 那道闸还在，单问 MCQ 依然切不了） |
| `cloud/scripts/render_subsplit.py` | 156-157 | 删掉 mcq 的 raise |

前端 0 改动。`split_eligible` 一变真，小问面板、切分开关、预览子图全部自动出现。

### 4.3 打标粒度

走默认 `top` 粒度（a/b/c），与物理一致。这些题每问 1 分，不存在会计那种 `(a)(i)` 嵌套，不需要 `SUB_DEEP_LABEL_SUBJECTS`。

## 5. 🔴 最大的坑：切分会剥掉整题已有的标签

`_save_split()` 会用 `_strip_annotation_lines()` 把主文件里的 `tags` / `difficulty` 删掉（切分题标签只允许落在子题文件里）。

而你截图里的 2021-06 WCH14 Q4 **已经打了 2 个标签**（滴定曲线图像 / 指示剂选择），卷进度 18/20。本地这份 `q04.md` 还是空的 —— 说明本地是旧副本，云端已有数据。

**不处理就会直接丢标。**

方案里建议一并做两件小事（改动很小、风险低）：

1. 前端 `toggleSplit()`（`App.tsx:418`）：切分开关打开时，把整题的 `tags` / `difficulty` 预填到每个小问草稿里（现在写死 `tags: []`）。
2. 后端 `_save_split()`：未提交的小问，`tags` 继承主文件（现在补的是空壳）。

效果：老师点"按小问打标"，每个小问已经带着整题原来的标签，只是复选/微调，不会丢数据。

## 6. 顺带发现的另一个问题（建议单列一轮）

4 题的选项热区分组不对：

| 卷 | 题 | 分 | 现有 part | 应有小问 |
|---|---|---|---|---|
| 2025-06 WCH15 | Q11 | 4 | 无 | a/b/c/d |
| 2026-06 WCH12A | Q6 | 2 | 无 | a/b |
| 2026-06 WCH15A | Q5 | 4 | 无 | a/b/c/d |
| 2025-10 WCH14A | Q2 | 3 | a, b | a/b/c |

原因：这几题的**化学结构图里有 A/B/C/D 图注**，被 `_option_rows_on_page()` 当成选项字母收走了（`_group_options` 于是分组失败，退回单组）。

好消息：**不影响打标和切图**（切点来自小问标签行，不是选项热区）。只影响下发给答题端的选项框坐标。

修法很干净：既然现在有了 subquestions 的切点，可以直接用「小问纵向区间」给选项行归组，比"字母重复即开新组"更可靠。建议放在第二阶段，别和主流程混。
