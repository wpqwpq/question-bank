# 标签判定细则

## 一、候选集从哪来

只用该题 API 返回的 `available_tags`（= 该卷单元的叶子标签，含跨单元开放的组）。

- Edexcel/AQA/CIE 各一份词表：`data/taxonomy/<board>/<qual>/<subject>.json`
- **单元自动判定**：卷号 → 单元（`store.unit_from_paper_code`）。Edexcel `WPH11→U1`、AQA `PH01→U1`、CIE `QP12→P1P2` / `QP42→P4`
- 跨单元开放（`taxonomy._CROSS_UNIT_SELECTABLE` / `_CROSS_UNIT_GROUPS`）：
  - AQA **U5（ph05）** 卷 → 候选里并进 **U1–U4 全部标签**（Section B 综合题要引用前四单元）
  - CIE **P1P2（qp1x）** 卷 → 并进 **P4 的「电场」组**（老课纲 AS 就考电场，现行课纲挪到了 Paper 4）
  - ⚠️ **AI 侧只能靠标签 id 的单元前缀认归属**（`u1-…` / `u3-…` / `p4-…`）。
    「带单元前缀的组名」是**打标台右栏的显示效果**，`fetch_paper.py` 不会给你，别拿它当判断依据；
    需要组归属就看 `available_tags[].group`（组 id）与 `available_groups[].unit`
  - 外部单元的标签**命中规则时照常可选**（这是有意开放的，不算越界）；但**没命中跨单元规则的卷，
    绝不允许用别单元的标签**——后端 `_validate_tags` 会 422 拒收

**每个候选标签带四个字段**（`fetch_paper.py` 全量递给你）：

| 字段 | 用途 |
| --- | --- |
| `id` | 落盘值，写进 `decisions.json` 的就是它 |
| `zh` | 中文名，报告里显示 |
| **`en`** | **英文术语名，语义拿不准时以它为准**——中文译名是二次加工，英文才是考纲原词 |
| `group` | 所属组 id，配合 `available_groups` 看它属于哪一类/哪个单元 |

**挑不出合适的就留空**，绝不跨单元/跨卷另找标签硬凑。

## 二、数量

**数量 = 该题实际考到的核心知识点个数。不按分值设下限**——6 分的大题只考一个点就只标 1 个。

分值只作**建议上限，非硬性**（题目确实考得更多可突破）：

| 题型/分值 | 建议上限 |
| --- | --- |
| MCQ（1–2 分） | 2（通常 1） |
| 3–5 分 | 3 |
| ≥6 分 | 4 |

拆分题：**按每个小问单独判**（小问的分值决定它自己的建议上限）。

判定口径：该标签描述的知识点是不是这个小问**考核的核心**？
- 是 → 填
- 只是沾边 → 填，但在 decisions.json 里标 `low: true`（进报告「低置信」）
- 完全不沾 → 不填（若整题都填不出，见下）

### 「波的图像」指位移图，驻波图案不算（2026-10-23 王培琪定）

`u2-wave-diagram`（波的图像）**只管三种图**：

- 横波的**位移–时间图**（y–t）；
- 横波的**位移–距离图**（y–x）；
- 纵波的**疏部/密部图**（压缩与稀疏的空间分布）。

**不标的情况：**

- **驻波图案**（数环数、看节线与波腹位置）→ 只给 `u2-standing-wave`（要判谐波次数再加 `u2-harmonic`），
  **不再叠 `u2-wave-diagram`**。审核实例：2020-01 WPH12 Q11(a) 的三环驻波图，人工删掉了 `u2-wave-diagram`。
- 光强分布图、衍射照片 → 走 `u2-intensity` / `u2-diffraction`，与波形图无关。
- 题干只给波形照片或装置照片、实际考的是别的量（波速、波长、频率）→ 按被考的量挂标签。

> 一句话：**"图像"标签看的是「被画的纵轴是不是位移」，不是「图里有没有波」。**

### 同组内选哪个标签：四个审核锚点（2026-10-26）

- **`u2-special-components` 就覆盖「电阻变化原因的微观解释」**（2026-10-23 王培琪定，原话：
  「这个是涵盖在特殊元件里面的。特殊元件的考法就是它们电阻变化原因的微观解释」）。
  所以下列题**一律主挂 `u2-special-components`，不是词表缺口、不要报 gap、不要加 `low`**：
  - 灯丝：V↑→I↑→温度↑→晶格振动加剧→电子碰撞频繁→漂移增长变慢→R↑（I–V 曲线变平）
  - 热敏电阻：温度↑→释放更多载流子→n↑→R↓
  - LDR：光照增强→载流子增多→R↓
  - 二极管：正向偏置与反向偏置的导电机制差异
  可再叠 `u2-ohms-law` / `u2-drift-velocity-equation` / `u2-potential-divider-principle` 作次标签，
  但**主线必须是 special-components**。
- **`u2-special-components` 不叠 `u2-resistivity`**（2026-10-26 王培琪定，原话：
  「这种题除非有明确说电阻率怎么怎么样，不然不要再包含电阻率了」）。
  考「温度/光照变化 → 晶格振动幅度或载流子数 → 电阻变化」的题，**主挂 `u2-special-components` 就够**，
  不要再加 `u2-resistivity` —— 题目讲的是元件的**特性**，不是材料的**电阻率**。
  只有下列情形才加 `u2-resistivity`：题干给出 ρ、要求算 ρ、或明确说「电阻率如何变化」。
  对照：2024-10 Q5（晶格振幅↑、电阻↑）只挂 special-components；
  Q15(a)（应变片求 ρ=RA/L）只挂 resistivity，不挂 special-components。
- **电动势 e.m.f. 的定义/含义** → `u2-charge-current-and-voltage`，**不是** `u2-internal-resistance`。
  审核实例：2020-01 WPH12 Q17(a) 人工把 AI 借的 `u2-internal-resistance` 改成了
  `u2-charge-current-and-voltage`。内阻标签只给真正涉及 **r** 的题（求 r、图像法测 r、r 变化的影响）。
- **惠更斯原理已单列**（`u2-huygens-principle`，应用波组）。见到「用惠更斯构造解释」→ 主挂它，
  `u2-diffraction` 作次标签（2020-01 WPH12 Q16a 即此组合，人工确认）。

### 终端速度只给「已经匀速」的题（2026-10-20 审核后定）

`u1-terminal-velocity` 是最好用也最容易被滥用的标签（12 卷用了 27 次，是使用量第一）。

**只有下面三种情形才标：**
- 题干明确说「reaches terminal velocity / moves at constant velocity」；
- 要求**求**终端速度（如 `determine the terminal velocity`）；
- 分析对象处在**匀速段**（v–t 图已走平、s–t 图已成直线）。

**下面这些不标**（改用阻力来源的标签）：
- 球刚释放、还在加速下落（→ `upthrust` / `viscosity` / `density`）；
- 只画了 a–t 或 s–t 图、要求解释形状（→ `kinematic-graphs`，图线趋平只是现象）；
- 降落伞/跳伞的**整个**过程（只有后半段匀速，若只问全过程受力变化，用 `newtons-second-law`）。

> 审核实例：2022 June q2（球在黏液中加速）把终端速度换成 `viscosity`；
> 2023 Oct q4（有阻力下落的 s–t 图）直接删掉终端速度，只留 `kinematic-graphs`。

### 抛体不打「匀加速直线运动」（2026-10-19 王培琪定）

**平抛 / 斜抛题一律不要再挂 `u1-uniformly-accelerated-linear-motion`。**

- `u1-uniformly-accelerated-linear-motion` 只给**专门沿一条直线做匀加速运动**的题：刹车、赛车加速、斜面直滑、自由落体/竖直上抛、测 g 等。
- 抛体虽然竖直分量是匀加速，但考的是二维分解，归 `u1-horizontal-projectile-motion` / `u1-projectile-motion-at-an-angle`（AQA 为 `u1-oblique-projectile-motion`，CIE 为 `p1p2-projectile`）就够了。
- 已按此口径回改 Edexcel U1 的 2020 jan/june、2021 jan/june/oct、2022 jan/june/oct、2023 jan 共 9 卷（12 个标注单元）。

## 三、主标签（primary_tag）怎么选

**每个标注单元恰好一个主标签**（契约见 `plans/主标签实施方案.md` §2，后端 `api._validate_primary` 强制）：

| tags 个数 | 你要做什么 |
| --- | --- |
| 1 | **不用管**。`decisions.json` 里 `primary_tag` 留空即可（后端自动补成它，显式落盘） |
| ≥2 | **必须**显式给 `primary_tag`，且必须是 `tags` 里的一个，否则 `apply_tags.py` 报错、后端也会 422 拒收 |

> 拆分题**逐个小问各给一个主标签**；留空的小问（`tags: []`）没有主标签，别硬补。

### 判据（按优先级往下试）

1. **分值占比最大**的那个——小问里分值最重的一段，通常就是主线；
2. **题干首问 / 首句的落点**——命题人多把主考点放在最前面；
3. **缺了它题就塌的那个**——去掉这个知识点题目不成立，说明它是骨架；
4. 仍打平 → 选**更具体**的（叶子标签优于上位标签，如 `u1-half-life` 优于 `u1-radioactivity`）。

### 反例（别这么选）

- ❌ 机械取 `tags[0]` / 按字母序 / 按词表顺序 —— 那是 `--auto-primary` 的应急行为，不是判断；
- ❌ 挑"最泛、覆盖最广"的当主 —— 主标签指向考点主线，不是集合的包络；
- ❌ 同一题所有小问都给同一个主标签 —— 每问各判各的；
- ❌ 给跳过题或留空小问补主标签 —— 没标签就没有主标签。

### 例（2026-10-16 首批）

| 情形 | tags | primary_tag | 理由 |
| --- | --- | --- | --- |
| a 小问只考受力图 | `u1-free-body` | 自动 | 单标签，后端补 |
| 同问考力矩 + 力的分解 | `u1-moments`、`u1-resolving` | `u1-moments` | 力矩是主问，分解是手段 |
| MCQ 跨两考点 | `u1-ohms-law`、`u1-charge-current` | `u1-ohms-law` | 题干先求电阻 |
| 8 分小问跨四考点 | 动能 / 弹性势能 / 牛顿定律 / 平衡 | 动能 | 前两问都在算动能，分值最重 |

## 四、三种例外情形

| 情形 | 处理 |
| --- | --- |
| **题目有问题**（图对不上题号 / 题干截断 / 选项缺失 / 小问结构对不上） | 记 `issue`（一句话），`skip_kind: "issue"`，**不打标**。⚠️ **绝不调用 `/flag`**——「此题有误」由人判断，AI 只在报告里说明 |
| **没有任何合适标签** | `skip_reason`，`skip_kind: "no-tag"`，留空 |
| **切分题里个别小问无合适标签** | 该小问 `tags: []`（**显式留空**，仍要出现在 `subs` 里），同一题的其余小问照常打标 |

> 后端 `api._save_split` 允许提交「本题小问的**子集**」，且**未提交的小问保持原样**（不会清空）。
> 所以“留空”必须显式表达：把该小问放进 `subs` 且 `tags: []`。`apply_tags.py` 已按此实现
> （空标签小问照样提交）；`make_report.py` 把它显示成灰色的「留空 · 无合适标签」。
> **不要为了凑满乱填；也不要以为“不提交 = 清空”——那是 2026-10-19 之前的旧语义。**

### 有小问的题一律按小问打标

`top_labels`（cut.json 顶层小问）**≥2 就必须提交 `subs`**，一个单元一条；`apply_tags.py` 会在整题提交时直接拦下。

- 小问标签必须逐字来自该题 `top_labels`（`a` / `b` / `c`…；`a i`、`b ii` 这类是**下一层**，不算顶层，别拿来当 label）。
- 顶层小问里如果还有嵌套（如 q16 的 a 下含 a i / a ii），**整段按顶层 `a` 判一次**，不要拆到第三层。
- 每个小问单独判标签、单独判主标签；某个小问确实没有合适标签 → 该小问 `tags: []`，其余照常提交。
- 图上明明有 (a)(b)(c) 而 `top_labels` 为空 → 切割数据缺失，记 `issue`，按整题打标并在报告说明。

**置信度低**（拿不准但有沾边标签）：照填 + 标 `low: true`。典型的「沾边但不完美」场景：
- 词表缺该知识点的专门标签，只能用相邻标签近似

## 五、词表缺口的处理

发现某类知识点整卷/多卷都没有对应标签时：

1. **不要自己改词表**，写进 `decisions.json` 的 `vocabulary_gaps`
2. 报告会把它单列出来
3. 用户决定补标签后，用新标签重打相关题（用 `apply_tags.py --only <题号>`）

用户有可能会**自己在标签管理页加好标签**再回来让你重打——先读 `data/taxonomy/...json` 核对新标签的 **id**（手填常带拼写错误，如 `poerational` 应为 `operational`；刚建且无引用时直接改正重启词表即可）。

**建议新增/改名时给「短名」**（2026-10-17 用户明确要求「能省则省」）：中文名只留核心名词，
**不带并列（与/及）、不带括注、不带「：」**；需要覆盖面或限定条件时写进 `en`，不要堆在中文名上。
对照（用户实际砍过的）：测量不确定度与误差处理 → **不确定度与误差处理**；阻尼与阻尼振动 → **阻尼**；
光导纤维与模间色散 → **光导纤维**；特殊导体（LDR/二极管）→ **特殊导体**。

## 六、各考试局差异

| 考试局 | 备注 |
| --- | --- |
| **Edexcel** | 拆分保存会**真去切子图**（`render_subsplit`，产物 `qNN-a.webp`）；旧卷子题 id 是 `{qid}q15a` 这种格式，别自己拼 |
| **AQA** | 按小问打标**不切子图**（`SUB_NO_IMAGE_BOARDS`），只写子题文件；题型取自封面阅卷表；内嵌选择题不挂热区 |
| **CIE** | 同 AQA 不切子图；P1 卷（QP1x）的 MCQ 题 `subquestions` 为空、不可拆；老课纲内容（电场/运放/数字信号）散落，注意跨单元组 |

## 七、参考实例（2026-10-16 首批）

- **MCQ 1 分，跨两个考点** → 2 个标签（CIE qp12 Q30：欧姆定律 + 电荷电流电压）
- **structured 6 分，拆 a/b** → a 只考受力图给 1 个；b 考力矩+力的分解给 2 个
- **structured 8 分小问，跨 4 个点** → 4 个标签（动能 / 弹性势能 / 牛顿定律 / 平衡）
- **抛体题** → 用该局自己的抛体标签（Edexcel/AQA `u1-*-projectile-*`、CIE `p1p2-projectile`），
  **不要用「匀加速直线运动」代替**（2026-10-19 起作废旧做法，见 §二）

## 八、难度怎么判（2026-10-20 王培琪定；U1 七卷 + U2 八卷人工值校准）

> **默认不打难度**。只有用户明确要求「打难度」时才执行本节，并在 `apply_tags.py` 加 `--difficulty`。
> 每卷审核完跑一次 `scripts/diff_difficulty.py`，把新错法补进下面的锚点表。

难度五档：`very-easy` / `easy` / `medium` / `hard` / `very-hard`。

### 判定顺序（①→②→③→④→⑤，命中即停）

**① `very-easy`：直接读 / 直接背 / 纯概念判断**

- 看一眼就知道考哪个知识点，答案能直接背出或读出；
- **纯概念判断也算**：等重等距的跷跷板「合力与合力矩都为零」、哪行是两个矢量、弹性形变/弹性极限的描述；
- 不需要把概念对应到某个具体对象或图上的特征，不需要任何计算或单位换算。

**② `easy`：单步或两步，公式/关系由题面直接给**

- 套一个公式：F=σA、W=mgh、P=E/t、k=F/x、v=Δp/m、a=g sinθ；
- 直接代已给的比例关系（F→2F、k→3k 求伸长）；
- 选项已把方向/关系框好（匀速下滑哪个分量与阻力平衡）；
- **课本必背结论型的判断**：完全弹性碰撞「动量与动能都守恒」、最高点「速度为零但 a=g」——
  看着像要推理，其实结论在课本里背过 ⇒ 仍是 easy，别因为「要判断」就升 medium；
- **注意**：涉及「直径→半径」「cm/mm→m」这类换算再代公式，就**不是** easy（见 q16b 教训）。

**③ `medium`：标准套路，但要自己搭一步**

- 3 步以上、**且含单位换算或中间量换算**（v=距离/时间 → r=直径/2 → 6πηrv）
- 由两个实验/载荷状态反求常量，再代入第三状态求目标量（弹簧先求 k、再求球重；2025-10 Q15a）
- 要自建关系式（位移差、力矩平衡方程、h=W/(ρgA)、F=Pt/d）
- 要先建立「谁等于谁」的映射（动量减少量 = 球获得的动量）
- **同一个方法用在非常规的轴/量上**：a–t 图面积=Δv、h–t² 梯度=g/2、a 恒定→s–t 是抛物线
- **双变量比例组合**：Δx∝L/A，四个选项里 L 与 A 各不相同，要逐个代进去比（2026-01 Q8）；
  只动一个变量的比例（2F/3k、A 加倍）仍是 easy
- **受力图**：2 分就要标全三个力的方向、作用点与相对大小（2026-01 Q11），默认 medium 起
- 要选切入点（取梯度还是取面积？扫全图找最陡段？）

**④ `hard`：多步反推、综合计算或需组织完整解释，但关键关系可识别**

- 多步反推（测 g 偏大：按晚→t 偏小→g 偏大）；若只是常见秒表反应时间占比大、解释单一误差来源，可能仅 `easy`（2025-10 Q13a）
- 多步综合计算，但所需公式与对象关系明确
- 分析一个变化过程/因果链，如三阶段加速度、出水张力、开伞后加速度、射程为何有最大值
- 数值口径陷阱（每根管 vs 总量、力臂投影），但若只有一个明确陷阱，先判 `hard`
- **多因素比较解释**：要串 2 条以上因果再列原因才答全（2026-01 Q18b「g 大→飞行时间短→射程短」+ 两个偏差来源）
- 需组织多个得分点或作比例图；不要仅凭分值、步骤数或「有不确定度」字眼升档
- **合并单元里小问 ≥4 且作答形式跨两种以上（计算＋作图＋文字解释）**：即使每步都标准也判 `hard`（第 38 条，
  2026-10-29 CIE 首卷审核；同卷 8 分 3 问仍是 medium，判据是小问数与形式，不是分值）

**⑤ `very-hard`：关键一步「几乎没人想得到」**

不是「算得多」，而是**有一个学生普遍想不到的点**，想到就简单、想不到就全错。七卷共出现 5 个有效样本，均有明确的隐藏关系/组织难点：

- 刹车能量回收效率：输入**要把上坡的重力势能增加也算进去**，学生容易只算动能（2025-06 Q14）
- 三个力臂都要按各自角度投影，角度基准不同（2025-06 Q19b）
- 三阶段功率分析要逐段追踪动能、重力势能与功率去向（2025-10 Q18b）
- 动量变化题要跨对象、跨时间比较不同质量物体的动量增量，不能只凭「同为自由落体」推相同变化（2025-10 Q10）
- **同一装置在正接与反接两种情形下结论相反**：光电管铜网接正极时吸引光电子、有电流；反接后铜网为负极、
  电子被排斥、电流归零（2023-10 Q17a）。课本只示范正接。
- **同一原理在相邻两种情形下结论相反**（2023-10 Q18d 指纹传感器）：脊处皮肤贴住玻璃、无空气层 → 光透射进皮肤（暗）；
  谷处残留空气层 → 玻璃–空气界面全反射（亮）。两种机制并存，只讲全反射那一半就答不全。
- **「两种连接/两种状态的比值」要先各自算再比**：并联电阻是串联的 1/4，但要先用图算出 R、再意识到
  灯丝温度不同时 R 会变、比值并不严格等于 1/4（2023-06 Q16b）。
- **反着用相干条件**：拍现象里两源频率不同 → 相位差随时间线性变化 → 周期经历同相与反相，
  课本背的是「相干才产生稳定图样」，想不到「不相干反而产生周期性起伏」（2022-10 Q15a）。

**very-hard 的统一判据（2026-10-24 十一卷共 5 个有效样本，占 313 单元 1.6%）：**
**同一装置、同一原理，在相邻的两种情形下给出相反结论，而课本只示范其中一种。**
判 very-hard 前先问：这题是不是要求学生在两个「长得很像」的情形之间做区分，并各自给出不同结果？
是 → very-hard；只是「难算」「链条长」→ 最多 hard。
- **水波/声波的连续折射最终走到全反射，且方向与直觉相反**：海水声速随深度先减后增，声线**始终向声速小的
  一侧弯**，因此上下两段弯曲方向相反（700 m 附近为声道轴）（2020-06 WPH12 Q16a）。王培琪原话：
  **「水折射直到全反射的问题确实应该是 very-hard，主要是它很难被想到」**——难点是「根本想不到会往这个方向弯」。
  注意：**不是「算得多」，也不是「要对照两张图」，而是方向本身反直觉。**
- ~~主动用波模型做定量反证（2020-06 Q14c）~~ —— **此条作废**：该题的 very-hard 是审核时看错题造成的误判
  （王培琪 2026-10-23 确认），不作为锚点。

判 very-hard 前先自问三句：
1. **这题的难点是一个「想不到」的洞察，还是只是「算得多」？** 后者最多 hard。
2. **这个洞察在课本里有没有明写？** 课本讲过的对比（如光电效应里「电子可只转移部分能量、光子必须整体吸收」）
   学生背过，**最多 hard**——2021-01 WPH12 Q14 就是这样被降档的。
3. **能不能指认一个「学生不会主动去做」的动作？**（主动换模型反证、主动找不对称的因果方向）
   指认不出 → 不是 very-hard。

**两条总规律（写进判定顺序的注脚）：**

1. **very-easy 的门槛是「无动作」**：答案是一个定义、一个名词、一条单一事实，且**不需要**做概念翻译、
   逐项排除、图上定位、单位对号中的任何一件。**任做一件 → easy 起。**
2. **「解释」不是一档**：先问「是不是课本固定句式」——是 → easy；要自己搭因果链 → medium；
   多阶段/多状态追踪 → hard。别只凭「Explain 就是难」升档。

| Q16(c) 补全空槽/满槽两幅光路（4 分） | medium | **hard** | 结论虽已给（空亮满暗），但要**各自画出全反射与折射两条正确光路**，两套机制 |

**三条修正：**

35. **「要自己构造图形」→ medium 起**：课本有范例、照抄形状的（两端固定基频驻波）是 easy；
    要自己想出「中点一个节点」这种非默认形状的 → medium。
36. **「补全光路图」→ 至少 medium，两套机制并存 → hard**。画图不是"照形画"时，要把机制落到线条上。
37. **extended writing 要看「是不是分项独立」**：一条链（双缝干涉 6 分）→ medium；
    **分项各解释一件事**（Q17 三项各一句）→ hard。
38. **合并单元（一个大字母下挂 ≥4 个小问）→ `hard` 起**（2026-10-29 CIE 首卷审核）：一个标注单元里
    小问堆得多时，难度按**整段作答负担**判，不按「最难的那一步」判。判据：小问 ≥4 **且**作答形式跨两种以上
    （计算＋作图＋文字解释）⇒ 即使每步都是标准套路也给 `hard`。反之 3 个小问以内、形式单一，仍按 ①~⑤
    逐条走，**不因分值高升档**（同卷 Q3(b) 8 分 3 问 → medium，老师未改）。

**由此得到 CIE P1P2 的偏差修正（两卷 5 处判错全为判低的直接结论）：**

> 在 CIE P1P2 上判完难度后，**只要题目含「自己构造图形 / 自己推单位量纲 / 自己搭一步关系」，

> 而纯背诵型（定义、课本结论单点）两卷 0 处判错 —— **偏差只发生在「要自己动手搭」的题上**。

配套两条细则：

- **「求某量的 SI 基本单位」= medium**（不是 easy）：「瓦特 = J s⁻¹」那种一对一替换是 easy，
  但力矩要从 N m 拆到 kg m² s⁻²、涉及两步量纲展开 → medium。
- **「由 v–t 图画 distance–t 图」= hard**：要构造新曲线（斜率等于速度），不是把现成图换个轴；
  同类还有「由 s–t 图画 v–t 图」「由 a–t 图画 v–t 图」。**换轴读数是 medium，重画是 hard。**

#### 词表口径补充（王培琪 2026-10-29 定）

- **弹性形变 / 塑性形变的定义挂 `extension-graph`（拉伸图像）**，词表里本来就有，**不算缺口**；
  以后遇到「弹性极限 / 是否发生塑性形变」这类判断，直接用 `extension-graph`，别再借 `hookes-law`
  （`hookes-law` 只给「F ∝ x 成立 / 比例极限」那种明确讲定律的题）。

### 几条纪律

- **标签数量、分值都不是难度的判据**：3 个标签可能只套三个公式（medium），1 分题可能到 hard。
- **难度按每个小问各自判**，不因大题整体难就把所有小问抬高。
- **拿不准时依次问**：① 直接读/直接背/纯概念 → very-easy；② 公式题面给、两步内 → easy；
  ③ 要自己搭关系、换轴、或含单位换算的三步 → medium；
  ④ 反直觉多步、误差推理、变化过程、口径陷阱 → hard；
  ⑤ 有一个「几乎没人想得到」的洞察 → very-hard。
- **判完自查分布**：very-easy 约 9%、easy 约 32%、medium 约 37%、hard 约 19%、very-hard 0~2%。
  very-easy 超 12% → 多半把「要对应/要换算」的错放了；hard 超 25% → 多半把「步骤多」当「思路难」；
  very-hard 超 5% → 把「算得多」当「想不到了」。
- **给出的难度必须能一句话说清理由**（`difficulty_why`），写清走的是 ①~⑤ 哪条、卡在哪一步。

### 标签口径（11 个）

| 标签 | 给 | 不给 |
| --- | --- | --- |
| `u3-experimental-procedure-design` | 「怎么测 / 怎么装 / 怎么控制变量 / 怎么改」；**只描述做法不算计算**（如「说 rate = 体积/时间」） | 已经有明确公式要算的 |
| `u3-safety-precautions` | 题目真问风险（identify a safety issue / hazard） | **安全语境的判断题不算**：如「justify 学生做这个实验是安全的」落点是算应力比较 → 归 calculating-data |

| `u3-improving-measurement-accuracy` | 提改进措施（更精密的仪器、多次重复、加大读数、对准视线） | 只指出误差来源、没提改进 |

| `u3-uncertainty-calculation` | 最大/最小值、百分比不确定度、绝对不确定度 | 单纯误差来源讨论 |
| `u3-data-processing` | ① Criticise results ② 补全/整理数据表 ③ **为作图而加工数据**（取 lg/sin/平方、逐行算成新的一列） | 单纯照原数据描点 → 只 graph-plotting |
| `u3-analysis-of-error-sources` | 指认系统/随机误差来源、说明某项缺陷如何影响结果 | 提出了改进办法 → 叠 improving，primary 给 error-source |
| `u3-graph-plotting` | draw/plot/sketch 图、加最佳拟合线、「该画什么图」的图形方法 | — |
| `u3-graph-analysis` | 从图上**取斜率/截距/外推交点**再求物理量 | 直接在某点上读数且一步出结果（这种可以 easy） |

**作图三件套的关系（B 口径）**：照数据直接描点只给 `graph-plotting`；**要先对数据做加工才能画**
（如 sinθ₁–sinθ₂、先算 P=VI 再作 P–T）就再加 `data-processing`，primary 仍给 `graph-plotting`。

**主标签**：多标签时取**更专门/更高阶**那个，不按分值 —— 图形方法题 primary 给 `graph-plotting`；
不确定度题 primary 给 `uncertainty-calculation`（哪怕算 n 的分更多）；误差来源 + 改进 → primary 给 `error-source`。

**词表缺口**：「为什么厂家要做这类测试」这种**实验结论的工程/应用意义**没有标签 → 借
`experimental-procedure-design` + `low: true`（王培琪 2026-10-27 定：不值得为它加标签，出现很少）。

### 难度锚点（U3 专用）

| 档 | U3 长什么样 |
| --- | --- |
| `very-easy` | 1 分、一句话、常规做法/术语（「说一个升温办法」）。**要在图或表上定位的 1 分题不算** |

| `hard` | **要自己构思做法**：给目标不给路径的改良方案（「用同一套装置怎么拿到更准的值」）、自己搭「算一列 → 作图 → 取梯度」整条链路；**或点数/细节多、极易丢分的综合题**（U6 尤其：三组数据逐一比对下结论、整题写详细计划、不确定度要先绝对→百分比转化再合成） |

- ❌ **判低**：把「要自己想办法」当「多算几步」（q 3f、1d 都被判低到 hard）；把「外推/找交点」当「读图」。
- ❌ **判高**：1 分常规做法题给 easy（应 very-easy）。

**两条 2026-10-27 审核后补的判低点（U6 尤其明显）**：
- **「加工数据 + 作图 + 取斜率/截距」三连 = hard**（U6 2020-june 3c、2021-jan 3b、2021-june 3b；U3 2021-june 4b、2022-jan 4a）。
  只作一件事（哪怕 5 分完整作图）仍 medium。

  算 Δt 再判断 μs/div 是否合适（U3 2022-jan 5a）。
- 🔴 **选仪器类的题，只要结论要靠「算一个百分比不确定度」得出，就必须同时挂 `uncertainty-calculation`**
  （U6 2023-june 4b：Explain why vernier calipers are suitable… your answer should include a calculation
  → resolution + uncertainty，primary 给 resolution）。只讲「分度更细」而不要求算的，仍只挂 resolution。

  Moseley 的 Z ∝ f^0.5）。形式上像「比一比」，实质上要先判定自己数据的可信区间。

### 🔴 2026-10-27 大批量审核后的「medium 判高了」修正（U3+U6 全量 43 卷、236 单元、判错 10 = 4.2%）

这一轮 10 处错误里 **9 处是 medium 判高、1 处 easy 判低**，全部集中在三类例行两步题：
